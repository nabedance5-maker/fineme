Fineme belle

「変わりたい人に、地図と羅針盤を届ける」という仕組みを、女性にも。
外見を起点に、自信を再設計する旅は男女を問わない。

Naming

Fineme belle（ファインミ ベル）

belle — フランス語で「美しい」「素晴らしい」「見事な」を意味する女性形容詞。
英語の beautiful に相当し、外見だけでなく知性・内面の美しさも内包する。
名前の由来
フランス語の女性形容詞 belle は「美しい女性」という名詞としても使われる。

世界的名作『美女と野獣』の主人公ベルは、外見だけでなく知性・自分らしさ・優しさを持つ女性として描かれ、Fineme の「外見を起点に内面まで変容する旅」の思想と重なる。
Fineme思想との一致
Fineme の哲学
「外見を整えることで生まれる小さな自信が、人に優しくなれる余白をつくる」

belle は外見だけの美しさではなく、内面から溢れ出る美しさも指す。この二重性がそのまま Fineme の変容思想と合致する。
Concept

Fineme が持つ仕組みをそのまま女性へ

Fineme の核心は「診断 → パーソナライズされた地図（New Me Map）と羅針盤（Fineme Compass）の提供」という仕組みにある。この仕組み自体は性別に関係なく価値を持つ。

外見を変えたい女性に対して、何をやっていけばいいかを示す地図と羅針盤を届ける — それが Fineme belle の使命。
Fineme（男性向け）
恋愛に悩む男性が外見を磨くためのサービスを探し、変容の旅を歩むインフラ。

ジム・メイク・ヘア・骨格診断・婚活写真など男性の変容に特化したサービス群。
Fineme belle（女性向け）
外見を起点に自信を再設計したい女性のための、同じ地図と羅針盤の仕組み。

スキンケア・パーソナルカラー・ネイル・ヘア・エステなど女性の変容に特化したサービス群。

URL Architecture

fineme.me/belle/ 配下に展開

別ドメイン（belle.me 等）ではなく、fineme.me のサブディレクトリとして展開する。これにより fineme.me に蓄積された SEO ドメイン力をそのまま belle に引き継ぐことができる。
fineme.me/
  search/  ← 男性向け検索
  diagnosis/  ← 男性向け診断
  mypage/  ← 男性向けマイページ
  belle/  ← 女性向けトップ
    belle/search/  ← 女性向け検索
    belle/diagnosis/  ← 女性向け診断
    belle/mypage/  ← 女性向けマイページ
⚠️ 実装時に訂正済み： 当初「belleへのリンクは男性向けページのフッターにのみ」という混乱防止設計を想定していたが、実装時に「男女対等な導線」へ是正された（2026-07-24 commit「/aboutの二トラックを対等な導線に是正」）。現在は流入経路（SEO・広告・SNS）が belle 配下に直接誘導する設計は維持しつつ、サイト内の主要導線でも両トラックが対等に見える形になっている。
Admin Architecture

管理画面は共通・データで分岐

運営管理画面（/admin/）
渡邉が両方を管理するため共通のまま使用。各データに target フィールドを追加し、男性向け / belle / 両方 でフィルタリングする。
掲載者管理画面（/provider/dashboard）
掲載者も共通画面を使用。登録時に「どちらのサイトに掲載するか」を選択。男女両対応サービス（ヘアサロン等）は both を選べば両サイトに自動表示される。
掲載情報の管理方針
区分 項目 管理方法
共通 店舗名・住所・連絡先・営業時間・支払い方法・施設写真・スタッフ情報 1箇所で入力 → 両サイトに反映
男女別 サービス紹介文・キャッチコピー・AIマッチングプロフィール・料金メニュー・ビフォーアフター写真 Fineme向け / belle向け をタブで別管理

Monetization

belle はマネタイズの拡張機会

既存掲載者（特に男女両対応のサービス）に対して「belle 追加掲載」のアップセルが自然に発生する。belle オープン時点でセールスターゲットが既に存在する状態を作れる。
プラン 掲載先 想定ターゲット
Finemeプラン 男性向けサイトのみ 男性専用サービス（AGA・ひげ脱毛等）
belleプラン 女性向けサイトのみ 女性専用サービス（ネイル・エステ等）
両サイトプラン Fineme + belle 男女対応サービス（ヘアサロン・パーソナルカラー・歯列矯正等）
ヘアサロン・スキンケア・ホワイトニング・骨格診断など、男女両方を対象にするサービスは belle 立ち上げ時のアップセルの有力候補。「belle が始まったので両サイト掲載にしませんか」というアプローチが自然にできる。
Technical Design

実装方針（belle 開始時）

サイト構造
app/belle/ フォルダを作成。Next.js App Router が /belle/ 配下のルートを自動生成する。男性向けと同じページ構成をベースに、女性向けのデザイン・文言・カテゴリで差分を作る。
DB設計
各テーブルに target: "male" | "belle" | "both" フィールドを追加。既存データは全て male に一括設定。/belle/ 配下の API は belle と both のデータのみ取得する。
実装コスト最適化： 最初は男性向けページをベースに /belle/ 配下にコピーして素早く立ち上げ、共通化・最適化は後から必要に応じて行う。「完璧より70点で回す」方針で進める。
