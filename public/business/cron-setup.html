Cron設定ガイド

Vercel Hobby プランのCron上限（2件）を超えたため、外部Cronサービス「cron-job.org」に移行します。無料で全件設定できます。

⚠️ YOUR_CRON_SECRET はプレースホルダーです。実際の値はVercelの環境変数 CRON_SECRET をご確認のうえ入力してください（このページ自体には実際の値を書きません）。

手順
1
console.cron-job.org でアカウント作成（メールアドレスのみ）
2
ログイン後、右上「CREATE CRONJOB」ボタンを押す
3
下の表の各行の設定を入力して保存（9件 × 3〜4分 = 約30分）
4
各ジョブ作成後、「右ページの動作確認」ボタンで疎通確認
共通設定（全ジョブ共通）
Request Method
GET
Header Name
Authorization
Header Value
Bearer YOUR_CRON_SECRET

※ auto-visited のみ Header Name が x-internal-key、Header Value が YOUR_CRON_SECRET（Bearer不要）

# 名前 URL スケジュール（JST） Cron式（UTC） 疎通確認
⚠️ cron-job.orgの「Schedule」入力欄はUTC基準です。上記の「Cron式（UTC）」をそのまま入力してください。
「Advanced」モードにするとCron式を直接入力できます。
