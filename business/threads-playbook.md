## 1. アカウント設計

- **名義**：でお個人（新規ペルソナは作らない）
- **アイコン/ヘッダー**：でお本人（元・非モテ→現役モデルの説得力を顔で出す）
- **狙う読者**：AIで副業・事業を自動化して稼ぎたい層／ニッチで個人ビジネスを始めたい層

### bio 案（ゼロ→成功ナラティブ＋note導線）

案A（実績が出る前・立ち上げ期）：
```
元・非モテ→AIで事業を丸ごと自動化して運営中の現役モデル
「センスも金もない普通の人」がAIでどこまで稼げるか実験中
稼ぎ方は👇のnoteに全部書いてます
（noteリンク）
```

案B（フロント実績が出た後）：
```
AIで事業(Fineme)を自動化・収益化してる元・非モテモデル
noteが◯日で◯部売れました
「僕もやってみたい」人へ、全手順は👇
（noteリンク）
```

> bio内の実数（◯部）は、フロントnoteの実績が出てから差し替える。

### note アカウント bio（既存アカウント流用・AIで稼ぐに全振り／でお 2026-07-05）

- 既存の外見改善も投稿しているnoteアカウントを**そのまま流用**。ただし**bioはAIで稼ぐに全振り**（外見改善には触れない）
- ルール：でお文体／自己減点しない（proof-of-work基調）／嘘・数字捏造なし。導線＝フロント有料note

**本命（案A・信頼×導線）**
```
AIで自分の事業をまるごと自動化して回してる現役モデル｜「コードは書けない普通の人」でも"寝てても進む仕組み"は作れる！ AIで稼ぐ・副業を仕組み化する方法を実体験で発信中｜稼ぎ方の全手順は👇のnoteに
```
**案B（ゼロ→成功強め）**
```
顔もセンスもスキルもゼロだった僕が、AIに事業を任せて収益化するまで｜"AIで稼ぐ"の再現手順を包み隠さず公開中｜副業・個人事業を「仕組み」にしたい人へ👇
```
**案C（フック強め・煽り）**
```
"稼ぎたいのに時間がない"をAIで終わらせる｜事業をまるごと自動化して、寝てる間に前へ進める方法を発信｜AI×収益化の全手順はnoteにまとめました👇
```

- **導線**：noteは自己紹介文にリンクを埋めにくい → フロント有料noteを**プロフィールに固定**＋クリエイターページのリンク欄にnote URLを設定して「👇」を実リンク化
- **実績が出たら**：bioに一行だけ実数を足す（例「noteが◯日で◯部」）。虚偽は入れない

## 2. 投稿5型（ローテーション素材）

### 型①：実績数字（最重要・売れる燃料）
- 目的：ロールモデルの「3週間38部」に当たる、**目に見える証拠**
- 例：
```
AIで書いたnote、公開◯日で◯部売れました！

正直、こんな普通の僕でも売れるんだ…って自分が一番びっくりしてます(笑)

何をやったか、次の投稿で全部話しますね
```

### 型②：ゼロ→成功の物語
- 目的：等身大の共感でフォロー動機を作る
- 例：
```
20歳の僕、マジで何もなかったんですよ

顔もセンスもお金もスキルもゼロ

そんな僕が今、AIに事業を丸ごと動かしてもらってます

「才能」じゃなくて「やり方」だったんですよね
```

### 型③：AI×事業自動化・収益化の気づき／持論
- 目的：ノウハウの片鱗を見せて「もっと知りたい」を作る
- 例：
```
AIで稼ぐって、実は「すごいアイデア」じゃないんです

誰もやってない小さいニッチ × AIの自動化

これだけ！

みんな大きい市場で消耗してるけど、逆なんですよね
```

### 型④：実演ログ（Fineme運用の裏側）
- 目的：本当に自動化してる証拠＝信頼。Claude Code/cronで記事・SNSが自動で回っている様子
- 例：
```
今、僕のnoteとX、ほぼ自分で書いてないんです

AIが毎朝下書きを作って、僕は選んで直すだけ

寝てる間に事業が進むの、一回味わうと戻れないですよ(笑)
```

### 型⑤：note予告・希少性
- 目的：販売への橋渡し（残部・値上げ予告）
- 例：
```
AIで事業を自動化する方法、noteにまとめました！

最初の◯部だけ ¥◯◯◯ にしてます
（読んでくれた人の感想で改善していきたいので）

埋まったら値上げします🙏
（noteリンク）
```

> すべて memory `user-deo-writing-style` で検証。「。」より「！」、1〜2文で改行、問いかけ・自己突っ込みを混ぜる。

## 3. 週次カレンダー（1日3投稿ベース／慣れたら4投稿）

| 時間帯 | 型 | 狙い |
|---|---|---|
| 朝（7-9時） | ①実績 or ②物語 | 一日の最初に「証拠 or 共感」 |
| 昼（12-13時） | ③気づき/持論 | スキマ時間に刺さる短い学び |
| 夜（20-22時） | ④実演 or ⑤予告 | 一番読まれる帯で信頼→販売導線 |

- 週の配分目安：①実績 週2〜3 ／ ②物語 週2 ／ ③気づき 週3〜4 ／ ④実演 週2 ／ ⑤予告 販売期に集中
- ロールモデル同様、**毎日継続**が最優先（数より継続）

## 4. X（@deo_fineme）↔ Threads の棲み分け・相互送客

- **X**：恋愛戦略・モテ系持論（既存方針）。ここに「AI収益化」は混ぜない
- **Threads**：AI×事業自動化・収益化ナラティブ＋note送客
- **相互送客**：プロフィール相互リンク。同一文の丸コピはしない（Threadsは物語長め・改行多め、Xは短文断定）
- ネタが被る場合は「切り口を変える」：Xは持論の一撃、Threadsは体験ストーリー化
