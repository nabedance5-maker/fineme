# Threads「AI経営」編集長システム 仕様（SSoT）

<!-- SOURCE: でお（スペック）× Claude Code（学習統合・実装）/ 最終更新: 2026-07-09 -->

> `app/api/cron/threads-draft/route.js` はこの仕様に従う。一次情報は `data/threads-facts.json`。
> 目的は変わらず **note収益**。Threadsは入口＝プロフ→note→ファン化の最上流。

---

## 0. コンセプト
- テーマ＝**「AI経営」**。AIを"使う"のではなく、AIに"会社を経営させる"。
- アカウントの正体＝**「AI会社の経営日誌」**（AI活用/Claude Code紹介アカウントではない）。
- 一言：**「AIを"使う側"から、AIに"働かせる側"へ」**。

## 1. ターゲット（初心者向け禁止）
- Claude Code / MCP / AI Agent / Cursor を触っている**中級者**。
- だが「自分が操作して働いている」「便利ツール止まり」「事業を自動化・収益化できていない」「AIを社員にできていない」層。

## 2. 追う指標（フォロワーに振り回されない）
- **プロフクリック率／保存率／コメント率／note購入率／変換率(Threads→note)**。
- インプレ・フォロワー数は追わない（カルチャーショック系は超reachでも売れない）。

## 3. 投稿構造（スレッド）
- **本文**：①2行で止めるフック→②違和感→③共感→④新しい考え方→⑤答えは最後まで書かない→⑥「続きはリプ👇」
- **リプ①**：本文の答え。保存したくなる価値提供。
- **リプ②**：自然にプロフ誘導。**noteは直接売らない・本文/リプにURLを貼らない**。「固定を見て」に寄せる。

## 4. 比率（販売投稿は禁止）
- 価値提供70%／AI経営日誌20%／note誘導10%。
- cron実装＝曜日×3枠の週次プランで value15 / diary4 / note2（週21枠）。

## 5. 文体
- 短文。改行多め。**一文40字以内**。断言。テンポ。前置きなし。

## 6. 売れる原理（でおメモ `~/MyBrain/raw/20260708.md` ＋ 参考note学習）
- **読者の悩みから逆算**（自分の言いたいことでなく）。
- 売るのは情報でなく**"変われる未来"**（現場から抜けてAIに経営させる姿）。
- **無料で信頼／有料で変化**。読者の言葉で書く。
- **AIは編集者であってゴーストライターではない**：生の一次情報・感情を先に入れ、AIは構造化する。

## 7. 一次情報の3段ソース（AIは編集者）
1. `data/threads-facts.json` の **seeds**（でおの"今日の生ネタ"）＝最優先。
2. **facts**（Fineme実運用の事実プール）から鮮度づけ。
3. 一次情報が無い時のみ一般論。
- 虚偽の数字は書かない（実数は「◯」）。

## 8. プロフィール＝ポートフォリオ運用（変換の要・でお手動）
- 新規は最初の2〜3スクロールでフォロー判断。
- bioは中級者に一撃／固定＝最も保存された投稿 or note入口／低パフォ投稿は非表示に整理。
- 週次チェック：上部3スクロールの見え方／固定の更新／伸びなかった投稿の整理。

## 9. 自走PDCA
- でおが週1で「保存/プロフ誘導/コメントが効いた投稿」を `threads-facts.json` の **feedback** に追記（or メール返信）。
- 日曜、cron が feedback ＋直近投稿から**来週方針**を生成し `sns_posts(channel='threads_strategy')` に保存。
- 翌週の生成がその方針を読み、当たり型を厚く・外れ型を減らす。

## 10. ガードレール（不変）
- 嘘・数字捏造なし／読者・過去の自分を嘲笑わない／実スタックは Claude Code（外部ノーコードツールを"使ってる"と書かない）／日本語のみ（ハングル等除去）／noteは直接販売しない。
- 禁止：初心者向けAI活用術・便利ツール紹介・AIニュース・ChatGPTの使い方・プロンプト集・抽象論だけ・薄い自己啓発・ポエム・押し売り。

## 11. 出力（編集長メモ付き）
各パッケージ＝■投稿本文／■リプ①／■リプ②／■投稿の狙い／■なぜこのフック／■想定コメント。メールでコピー用＋編集長メモを届ける（でおが学べる形）。
